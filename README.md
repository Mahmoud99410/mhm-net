# MHM NET

تطبيق أندرويد لمراقبة وإدارة الإنترنت:

1. **الرئيسية** — استهلاك اليوم / آخر 7 أيام / الشهر، مفصول بين الواي فاي وبيانات الهاتف، مع السرعة الحالية ورسم لآخر 7 أيام.
2. **الحجب** — حجب الإنترنت عن أي تطبيق (أو كل مواقع التواصل بضغطة): 15 د، 30 د، ساعة، ساعتان، 3 ساعات، مدة مخصصة، حتى تعيد التفعيل، أو يومياً في وقت محدد. يعمل عبر VPN محلي داخل الهاتف فقط.
3. **الشبكات** — قياس سرعة التنزيل والرفع بـ MB/s لكل شبكة (M 4g و M 5g) والتبديل التلقائي إلى الأسرع كل 15/30/60/120 دقيقة.
4. **التطبيقات** — إحصائيات استهلاك كل تطبيق (واي فاي / بيانات) في تبويب منفصل.

## البناء عبر GitHub

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `mhm-net`).
2. ارفع كل محتويات هذا المجلد (بما فيها مجلد `.github` ومجلد `keystore`).
3. من تبويب **Actions** افتح آخر تشغيل لـ **Build APK** وانتظر حتى ينتهي.
4. حمّل الملف من قسم **Artifacts** باسم `MHM-NET-apk` وفكّ الضغط للحصول على `MHM-NET.apk`.

ملف التوقيع `keystore/mhm-net.jks` ثابت، لذلك كل نسخة جديدة تُثبّت فوق القديمة بدون حذف البيانات.

## أول تشغيل

- اسمح بإذن **الموقع** وشغّل **GPS** (أندرويد يشترطه لمعرفة اسم الواي فاي).
- فعّل إذن **الوصول إلى بيانات الاستخدام** لـ MHM NET.
- عند أول حجب اسمح بإنشاء **VPN**.
- في تبويب الشبكات: استثنِ التطبيق من توفير البطارية، ويمكنك إدخال كلمة مرور الشبكتين (اختياري) إذا رفض أندرويد التبديل.

## ملاحظات تقنية

- `targetSdk 28` مقصود: آخر مستوى يسمح للتطبيق بتبديل الواي فاي بنفسه. قد يظهر تحذير من Google Play Protect لأن التطبيق "مصمم لإصدار أقدم" — اختر «التثبيت على أي حال».
- اختبار السرعة يستخدم خوادم Cloudflare (speed.cloudflare.com) ويستهلك تقريباً 20–100 ميجابايت لكل شبكة.
- الحجب لا يعمل مع VPN آخر في نفس الوقت.
